# Changelog

## 0.1.0

- Add persistent WebSocket trigger with None, Bearer, Basic Auth, header, query and subprotocol authentication.
- Add encrypted secret headers/query fields and a real handshake credential test.
- Add query parameters, Origin, subprotocols and subscription messages.
- Add reconnection with backoff/jitter, retry budgets and ping/pong heartbeat.
- Add JSON, text and binary outputs with ordered conversion and a bounded pending queue.
- Add dedicated SVG icons for light and dark n8n themes.
- Add automated transport/trigger tests, package verification and npm publishing workflows.
